# 🌐 Abigiya Getachew Assefa Portfolio

A personal portfolio showcasing selected projects, technical skills, and contact information.

Built with **React, TypeScript, and Vite**, the site provides a responsive and accessible interface with a downloadable resume.

---

## ✨ Features

* Responsive homepage layout
* Hero section with resume download option
* Project cards with live links and outcomes
* Horizontal scrolling for projects beyond three items
* Skills grouped by frontend, backend, tooling, and practice
* Direct contact links for Email, GitHub, and LinkedIn
* Copy-to-clipboard email interaction with feedback
* Mobile-friendly navigation
* Semantic landmarks and visible focus states
* Reduced-motion support

---

## 🛠 Tech Stack

**Frontend:** React 19, TypeScript, Tailwind CSS 4, Radix UI, Lucide React, Wouter

**Tooling:** Vite, pnpm workspaces

## 🚀 Getting Started

### Install dependencies

```bash
pnpm install
```

### Start the development server

```bash
pnpm dev:client
```

The application will run locally, typically at:

`http://localhost:5173`

---

## 📜 Available Scripts

| Command           | Description                              |
| ----------------- | ---------------------------------------- |
| `pnpm dev:client` | Start the Vite client development server |
| `pnpm check`      | Run TypeScript checks                    |
| `pnpm build`      | Create a production build                |
| `pnpm format`     | Format the repository with Prettier      |

Client-specific commands can also be run from the `client` directory:

```bash
pnpm --dir client check
pnpm --dir client build
pnpm --dir client preview
```

## 📝 Content Management

### Resume

The resume PDF is located at:

```text
client/src/assets/ABIGIYA_GETACHEW_ASSEFA_CV.pdf
```

Download links are integrated into the Hero, Navbar, and About components.

### Projects

Project data is managed in:

```text
client/src/components/portfolio/Work.tsx
```

Each project includes:

* Title
* Description
* Outcome
* Tags
* Image
* URL

Projects without a URL display a **Link coming soon** state.

---

## 🌍 Deployment

Build the client before deployment:

```bash
pnpm --dir client build
```

The production output is generated by Vite and can be deployed to platforms such as Vercel, Netlify, or GitHub Pages.

For Vercel, configure the project to use the `client` directory as the root directory.
